# Hello World in REST API with PHP

This is a basic project that implements a REST API using PHP. The purpose of this project is to respond with a JSON message "Hello World with RestApi in Php language" when a request is made to the server.

## Clone the repository

```bash
git clone git https://github.com/Karen020701/AppRestApi-php.git
```

## Start the server

To start the server you must:
Make sure that the PHP file is called `server.php`.
In the terminal run the command with its respective paths:

```bash
cd /path/to/your/project
```

Once in the folder, run the following command to start the PHP server:

```bash
php -S localhost:8000
```

Once the server is running go to: *http://localhost:8000/server.php* and you will see the message.
